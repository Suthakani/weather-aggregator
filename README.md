# Weather Aggregator 🌦️

A professional weather dashboard built using HTML, CSS, JavaScript, Node.js, Express.js, and OpenWeather API.

## 🚀 Features

✅ Current Weather Information  
✅ Temperature Charts using Chart.js  
✅ Dark/Light Mode  
✅ Favourite Cities  
✅ Current Location Detection  
✅ Responsive and Modern UI  
✅ Dynamic Weather Backgrounds  

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- OpenWeather API
- Chart.js
- Git & GitHub
